How it works

  1. Upload an audio file (lecture, podcast, interview, etc.)
  2. Paste the full transcript — the app splits it into sentences automatically
  3. Click Align sentences — the app transcribes the audio with Whisper and matches your transcript using fuzzy alignment
  4. Each sentence gets a start time, end time (including trailing silence), and duration
  5. Download the results as CSV or JSON

Audio files are processed in memory and deleted immediately. No data is stored on the server.
